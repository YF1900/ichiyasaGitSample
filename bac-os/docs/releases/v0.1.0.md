# v0.1.0 - 初期リリース

**リリース日**: 2026-04-04

## 概要

BaC OS（Business as Code）の初期バージョン。
ビジネスの制約→仮説→実験→学習のサイクルを管理する基盤を構築。

## 追加

- Constraint Canvas（制約管理）CRUD
- Hypothesis Engine（仮説管理）CRUD
- Experiment Tracker（実験管理）CRUD
- Feedback Logger（学習管理）CRUD
- KPI Dashboard（統計表示）
- AI Prompt Center（プロンプトテンプレート）
- Release Viewer（リリースノート管理）
- 構造化ログシステム
- Zod バリデーション

## 技術スタック

- Next.js (App Router)
- TypeScript (strict)
- Tailwind CSS
- Prisma + PostgreSQL
- Recharts
- lucide-react

## マイグレーション

初回セットアップ:
```bash
npx prisma migrate dev --name init
```
